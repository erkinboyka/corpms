# Дизайн-система рабочего пространства

Компоненты работают в Blade и используют локальные CSS и JavaScript из `public/assets`. Значения тем определены в `workspace.css`, базовая типографика и кривые движения — в `tokens.css`.

| Токен | Применение |
|---|---|
| `--bm-canvas` | Фон страницы, подложка групп |
| `--bm-sheet` | Непрозрачная поверхность таблицы или формы |
| `--bm-panel` | Матовая навигация и всплывающие панели |
| `--bm-ink`, `--bm-muted` | Основной и вспомогательный текст |
| `--bm-line` | Разделитель, край поля или карточки |
| `--bm-link`, `--bm-selected` | Акцент, клавиатурный фокус и выбранный пункт |
| `--bm-heading`, `--bm-round` | Размер заголовка и радиус панели |
| `--bm-gutter` | Внутренний отступ заголовка на разных ширинах |

## Компоненты в приложении

| Компонент | Экран | Состояния |
|---|---|---|
| Форма доступа | /login | Автозаполнение, видимость пароля, фокус, ошибка |
| Реестр | /employees | Строка за рабочим столом, подписанные поля на узком экране |
| Сравнительная таблица | /finance/budgets | Числа по столбцам, прокрутка в пределах таблицы |
| Канбан | /crm/deals | Выбор стадии, перетаскивание, допустимая цель |
| Очередь | /tasks/mine | Назначенные и созданные задачи с независимыми страницами |
| Карточка записи | /documents/{document} | Переход к видимому разделу по заголовку |
| Боковое меню | /dashboard | Полная панель, компактный режим, мобильное раскрытие |

В обычном режиме кнопка поднимается на 2 пикселя при наведении точного указателя. При удержании кнопки масштаб уменьшается до 96,5%. Клавиатурный фокус обозначен отдельным контуром. Новые пространственные переходы работают при `prefers-reduced-motion: no-preference`. При выборе роли или данных набор доступных действий определяют существующие политики приложения.
