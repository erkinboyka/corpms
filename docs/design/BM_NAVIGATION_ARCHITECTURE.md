# Навигация BM Systems

`App\\Support\\Sidebar` формирует единый набор пунктов из прав текущего пользователя. Из этого набора строятся меню, палитра команд и вкладки модулей. Переход на детальную страницу выделяет её родительский раздел. Laravel продолжает проверять доступ к каждому маршруту.

| Область | Содержание |
| --- | --- |
| Обзор | Рабочий стол и уведомления |
| Работа | Задачи, проекты, графики, праздники и отпуска |
| Люди | Сотрудники, организация, посещаемость, ведомости и оклады |
| Клиенты | Клиенты, лиды, сделки и активности |
| Операции | Остатки, товары, склады, поставщики, движения и закупки |
| Финансы | Счета, операции, бюджеты, бухгалтерские справочники и отчёты |
| Документы | Общий и личный реестры, шаблоны и согласование |
| Аналитика | Аналитика, отчёты, BI, AI-ассистент и журнал действий |
| Администрирование | Учётные записи, интеграции, терминалы, RFID и настройки |

Вложенные группы по умолчанию свёрнуты. Группа текущей страницы открывается автоматически. Остальные группы запоминают выбор пользователя. На десктопе доступен компактный режим меню. На телефоне меню открывается кнопкой в верхней панели.

В задачах, CRM, посещаемости, финансах и документообороте основные представления доступны из строки ссылок внутри модуля. Поле поиска ищет сущности, а палитра `Ctrl+K` помогает перейти к экрану. Хлебные крошки показывают путь, кнопки страницы выполняют действия с текущей записью.
