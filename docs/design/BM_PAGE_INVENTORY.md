# Реестр экранов BM Systems

Реестр сопоставляет пользовательские GET-страницы с маршрутами из `routes/web.php`. Для доступа указаны требования входа или разрешения маршрута. Записи, действия и дополнительные ограничения определяют политики и контроллеры. Создание, редактирование, экспорт и согласование учитываются как действия, состояния или встроенные формы соответствующего экрана.

## Ошибки

Шаблоны для HTTP 401, 403, 404, 419, 429, 500 и 503 используют общий блок с объяснением и доступным действием. Это состояния приложения без отдельных пользовательских маршрутов.
