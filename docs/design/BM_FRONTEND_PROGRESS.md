# Прогресс редизайна BM Systems

| Область | Что реализовано |
| --- | --- |
| Оболочка | Компактное боковое меню, выделение родительских разделов, переход к основному содержанию с клавиатуры и единые главные заголовки |
| Рабочий стол | Приветствие, дата и время, общая полоса личных приоритетов, блоки задач и посещаемости |
| Задачи | Переходы между общим списком, личной очередью и просроченными задачами |
| Сотрудники | Каталог с управлением представлением и улучшенной иерархией имени в таблице |
| Посещаемость | Общая полоса статусов дня, отдельные переходы к событиям в реальном времени, табелю, аномалиям и корректировкам |
| CRM | Локальная навигация и прокручиваемая воронка сделок |
| Финансы | Баланс как основной показатель, табличное отображение сумм и переходы внутри модуля |
| Документы | Компактная сводка статусов и навигация по реестрам, шаблонам и согласованию |
| Проект | Ход выполнения задач рядом с контекстом проекта, затем бюджет и рабочие списки |
| AI | Диалог с историей и поле вопроса, быстрые вопросы в отдельной панели, понятные подписи статусов ответа |
| Авторизация | Единая рамка входа и восстановления доступа с читаемыми формами и сообщениями о валидации |

Изменения внесены в `resources/views/layouts/tabler.blade.php`, `resources/views/layouts/auth.blade.php`, `resources/views/partials/sidebar.blade.php`, `app/Support/Sidebar.php`, `public/assets/css/bm-ui.css`, `public/assets/js/bm-ui.js` и шаблоны перечисленных модулей.

## Проверки

- Blade-шаблоны компилируются, изменённые JavaScript-файлы проходят проверку синтаксиса.
- Проверены 65 прямых пользовательских маршрутов на изолированных данных. 63 вернули HTTP 200, учётные записи и интеграции вернули HTTP 403 для тестовой роли.
- Вход, роли, палитра, AI и поток событий прошли 19 целевых тестов.
- Ещё 49 проверок прошли для проектов, задач, документов, CRM, финансов, посещаемости и сообщений о валидации.
- В браузере проверены внешний вид входа и переходы между входом и восстановлением пароля.
- Сборка Vite остановилась на загрузке зависимости `@tailwindcss/vite`. Действующая оболочка использует локальные файлы из `public/assets`.

## Оставшаяся работа

[Реестр экранов](BM_PAGE_INVENTORY.md) описывает 77 пользовательских маршрутов и их текущие композиции. Для экранов, где применена общая оболочка, остаётся индивидуальное проектирование. Визуальная приёмка внутренних экранов на четырёх размерах, проверка состояний форм и диалогов и замеры производительности остаются открытыми. Текущий результат доступен в локальном Laravel-проекте.
