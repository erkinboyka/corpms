# CorpMS — Frontend Design Pipeline
## Артефакты этапов 01–03 (утверждённые)

---

## 01 · ART DIRECTION · DESIGN BRIEF

**Продукт**: CorpMS — корпоративная система управления (HR, табель, документооборот, задачи, биометрия). Пользователи — сотрудники и руководители крупных компаний; работают часами каждый день.

**Характер продукта**: серьёзный, надёжный, «quiet confidence». Не стартап-игрушка, не SaaS-шаблон.

### Design philosophy
1. **Calm density** — данные важны, декор нет. Всё лишнее убрано; плотность остаётся читаемой.
2. **Depth without noise** — глубина достигается стеклом (сдержанным), а не градиентами и тенями «для красоты».
3. **One accent** — единственный перивинкловый акцент (#8BA9FF) на нейтральном сине-сланцевом grunge-подмножестве. Аксцент — только для действия/активности.

### Visual direction
- «Refined Glass»: тонкая полупрозрачность, сдержанный blur (14px), тонкая рамка.
- На плоской тёмной базе (#10151D) — стекла дают иерархию: base → surface → elevated.
- Без узоров-текстур, без случайных градиентов, без б Kampata-объёмов.

### Color palette (dark — каноническая)
Base #10151D · Surface #171F2A · Elevated #222E3C · Border #344152
Accent #8BA9FF · Text #F3F5FA · Secondary #A0ACBC · Success #42C9A5

### Typography direction
- Системный умный стек (Inter → Segoe UI → system-ui), без вебшрифтов — скорость и серьёзность.
- Шкала: Display 32 · Heading 24 · Section 20 · Body 14–16 · Caption 12.
- Числа — табличные (данные в колонках не дрожат).

### Layout principles
- Grid 12 колонок; контент ≤ 1240px; отступы по шкале 4/8/12/16/24/32/48/64.
- Sidebar 256px (постоянный, тёмный) + топ-bar 56px.
- Иерархия экрана: page-header → KPI-ряд → основная зона (7/5 сечение) → вторичные блоки.
- Ничего не добавляется «ради заполнения».

### Glassmorphism strategy
- Стекло — ТОЛЬКО для: карточек, top-bar, dropdown, модалок, alert.
- Не для: таблиц внутри карточек (они прозрачны поверх), inout-полей (низкая aopacity), бейджей.
- Одиневый слой blur; вложенный blur запрещён.

### Component appearance
- Кнопки: radius 10, только primary насыщен; ghost — тихие.
- Input-ы: rgba-фон рамки по теме; focus — тонкое кольцо акцента.
- Бейджи статусов — темы Tabler (bg-*-lt), константы семантики из токенов.

### Visual references
- Vercel Dashboard (тихая плотность), Linear (акцентная дисциплина), Arc Browser (стекло без китча).

## 02 · DESIGN SYSTEM · Tokens v1.0
Реализация: `public/assets/css/tokens.css` (CSS variables), `effects.css` (поверхности/эффекты), `corpms.css` (мост на Tabler).

Полная таблица — в tokens.css. Ключевое:

| Группа | Токен | Dark | Light (derived) |
|---|---|---|---|
| Base | --crm-bg | #10151D | #E9EDF4 |
| Surface | --crm-surface | #171F2A / a.62 glass | rgba(255,255,255,.72) |
| Elevated | --crm-surface-raised | #222E3C | #F7F9FC |
| Border | --crm-border | #344152 | #CBD3DD |
| Accent | --crm-accent | #8BA9FF | #4F74E3 (кнопки/текст) · #8BA9FF deco |
| Text | --crm-text / --crm-text-secondary | #F3F5FA / #A0ACBC | #101823 / #5A6674 |
| Success | --crm-success | #42C9A5 | #17A583 |
| Danger/Warning/Info | производные | #E5697A / #E5B05C / #8BA9FF | #D64550 / #B7791F / #4F74E3 |

- Spacing: 4/8/12/16/24/32/48/64 → `--crm-space-1..8`.
- Radius: 6/10/16 (бейджи/кнопки/карточки).
- Effects: shadow-1/2, blur 14px, durations 120/200/320ms.
- Typography: см. brief.

**Правила использования** (жёстко):
1. Любой экран — только токены; никаких собственных hex.
2. Стекло — только через механический слой effects.css.
3. Бейджи — только Tabler bg-*-lt (семантика консистентна в обеих темах).

## 03 · LAYOUT · Спецификация первого экрана (Дашборд)

Viewport-референс: 1440×900. Sidebar 256px; content area 1184pxisure; container 24px паддинг.

### Структура
```
┌─ topbar (56px, sticky glass) ─────────────────────────────┐
├─ page-header: Заголовок (Heading/24) · дата (Caption/12) ─┤
│                                                            │
│ A. KPI-ряд (grid: 4 → 2 → 1)                              │
│    [Статус сегодня] [Мои задачи] [Подписи] [Согласования]  │
│                                                            │
│ B. Основное сечение 7/5                                    │
│    [Посещаемость (7)]        [Мониторинг задач (5)]        │
│                                                            │
│ C. Биометрия — полная строка-strip (12, только для держателей права)
└────────────────────────────────────────────────────────────┘
```

### Отступы
- page-header → A: 24px; A → B: 16px; B → C: 16px.
- Внутри карточек: header 12/16, body 16/24.
- KPI-карты: колэкшены одинаковые; цифры — Section/20, подписи — Caption/12.

### Иерархия
1. Точка внимания: цифры KPI.
2. Второй уровень: посещаемость (4 больших числа).
3. Третий: списки/полосы задач.

### Адаптив
- ≥1200: сетка 4/7-5.
- 768–1200: KPI 2×2; B свер profits стеком (12).
- <768: всё в стек; sidebar закрывается.

### Не утверждено (специально)
- Welcome-баннер карточкой удалён: дублировал page-header и был «90-е».
- Никаких добавленных блоков «ради заполнения».
